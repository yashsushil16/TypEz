2. Description of the Service

TypEz is a productivity tool for Google Chrome operating under Manifest V3 specifications. It provides:

  • Local Text Expansion: Triggered via the symbol ?, expanding local shortcuts stored in your browser's local sandbox without internet access.
  • AI Text Transformation: Triggered via the symbol !, which transforms selected paragraph text using user-provided API keys for Groq Cloud (Llama 3.1/3.3) and Google Gemini (2.0 Flash).
  • Optional Synchronization: An optional self-hosted or provided backend server for synchronizing snippet dictionaries across devices.
