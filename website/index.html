System Design

The Dual-Engine Approach

Most extensions either do dumb string replacement or slow cloud-only generation. TypEz splits duties cleanly between two purpose-built engines.

?
Local Engine (Offline)

Local Symbol Expansion

Instantly replaces predefined trigger codes without network calls, roundtrips, or external dependencies.

  • 0ms Sub-frame Replacement: Keystroke buffer monitors input streams and executes synchronous DOM substitution.
  • Completely Offline: All snippet dictionaries live inside your browser's chrome.storage.local.
  • Universal DOM Hook: Compatible with standard inputs, textareas, and rich contenteditable containers.

Privacy & Security

Built On A Zero-Telemetry Architecture

Text assistants often harvest every keystroke. TypEz is built from the ground up to respect your confidentiality.

01

Direct Client-to-API Calls

When using the AI engine, requests travel directly from the background service worker to Groq or Google's official API endpoints. There is no middleman server inspecting or storing your prompts.

02

Bring Your Own Key (BYOK)

Use your personal free-tier API keys from Groq Cloud and Google AI Studio. Your keys are stored exclusively in Chrome's encrypted storage sandbox on your device.

03

Scoped DOM Observer

TypEz only tracks keystrokes once an explicit trigger symbol (? or !) is typed. Normal typing is never buffered or recorded.

Install TypEz in 4 Simple Steps

Load TypEz into Google Chrome or any Chromium-compatible browser (Brave, Edge, Arc, Opera) in under two minutes.

1

Build Extension

Clone the repository and compile the React popup bundle using Vite.

2

Open Extensions

Navigate to the Chrome extensions manager and enable Developer Mode in the top right.

chrome://extensions
3

Load Unpacked

Click "Load unpacked" and select the extension/dist directory.

Select extension/dist
